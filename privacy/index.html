홈칵테일 개인정보처리방침

시행일: 2026-10-13 · 적용 앱: 홈칵테일 (Android, com.jusi1022.homecocktail)

1. 개요

홈칵테일(이하 "앱")은 칵테일 레시피와 주류 정보를 제공하는 Android 앱입니다. 앱은 회원 가입이나 로그인 기능이 없으며, 사용자를 식별하는 정보를 수집하거나 외부 서버로 전송하지 않습니다.

2. 앱이 다루는 데이터와 저장 위치

다음 데이터는 모두 사용자의 기기 안(앱 전용 저장 공간)에만 저장되며, 운영자나 제3자에게 전송되지 않습니다.

  • 내 Bar에 등록한 술과 재료(이름, 분류, 수량, 메모)
  • 즐겨찾기한 칵테일과 최근 본 칵테일
  • 앱 설정(화면 테마, 첫 안내 완료 여부, 자동 업데이트 여부)
  • 온라인에서 받은 레시피 데이터 사본과 업데이트 확인 기록

3. 네트워크 사용

앱은 다음 목적에만 인터넷을 사용하며, 이때 사용자 데이터를 보내지 않습니다.

  • 레시피 데이터 업데이트: 정적 파일(manifest.json, 릴리스 JSON)을 HTTPS로 읽어 옵니다. 요청에는 일반적인 HTTP 접속 정보(IP 주소, 요청 시각, 앱의 User-Agent) 외에 다른 정보가 포함되지 않으며, 이 정보는 호스팅 제공자(GitHub Pages)의 서버 로그에 남을 수 있습니다. 호스팅 제공자의 처리는 GitHub 개인정보처리방침을 따릅니다.
  • 외부 링크: 레시피 원본 영상(YouTube)이나 출처 페이지를 열 때 기기의 브라우저 또는 해당 앱으로 이동합니다. 이동한 뒤의 데이터 처리는 해당 서비스의 정책을 따릅니다.

인터넷에 연결되지 않아도 앱의 모든 기능을 쓸 수 있습니다.

4. 백업 파일

사용자가 직접 "내 데이터 백업"을 실행하면 내 Bar, 즐겨찾기, 설정이 담긴 JSON 파일이 만들어집니다. 파일은 사용자가 고른 위치에만 저장되고, 앱이 어디로도 전송하지 않습니다. 파일의 보관과 공유는 사용자의 책임입니다.

5. 제3자 SDK

앱은 광고, 분석, 오류 보고, 소셜 로그인 등 제3자 데이터 수집 SDK를 포함하지 않습니다. 앱에 들어 있는 오픈소스 라이브러리는 기기 안에서만 동작합니다.

6. 권한

앱이 요청하는 Android 권한은 인터넷 접근(INTERNET) 하나입니다. 위치, 연락처, 카메라, 마이크, 저장소 전체 접근 권한을 사용하지 않습니다. 백업 파일 저장과 불러오기는 Android의 파일 선택 화면을 통해 사용자가 고른 파일에만 접근합니다.

7. 데이터 삭제

기기 안의 데이터는 앱에서 직접 지우거나(내 Bar 항목 삭제, 즐겨찾기 해제, 받은 레시피 데이터 지우기), 앱을 삭제하면 함께 삭제됩니다. 사용자가 만든 백업 파일은 사용자가 직접 지웁니다. 운영자는 사용자의 데이터를 보관하지 않으므로 별도의 삭제 요청 절차가 필요하지 않습니다.

8. 아동의 개인정보

앱은 아동을 대상으로 하지 않으며, 연령과 관계없이 개인정보를 수집하지 않습니다.

9. 방침의 변경

방침이 바뀌면 앱 업데이트 또는 이 페이지를 통해 알립니다. 바뀐 방침은 공개된 시행일부터 적용됩니다.
