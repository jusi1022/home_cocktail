홈칵테일 개인정보처리방침

시행일: 2026-11-20 · 적용 앱: 홈칵테일 (Android, com.jusi1022.homecocktail)

1. 개요

홈칵테일(이하 "앱")은 칵테일 레시피와 주류 정보를 제공하는 Android 앱입니다. 앱은 회원 가입이나 로그인 기능이 없으며, 사용자를 식별하는 정보를 수집하거나 외부 서버로 전송하지 않습니다.

2. 앱이 다루는 데이터와 저장 위치

다음 데이터는 모두 사용자의 기기 안(앱 전용 저장 공간)에만 저장되며, 운영자나 제3자에게 전송되지 않습니다.

  • 내 바에 등록한 술과 재료(이름, 분류, 수량, 메모)와 사용자가 적은 구매 가격
  • 사용자가 직접 등록한 술·음료·재료(이름, 종류, 브랜드, 도수, 용량, 구매일, 메모)와 직접 쓴 칵테일 레시피
  • 직접 등록 항목에 붙인 사진: 사용자가 고른 사진 파일을 앱 전용 폴더에 복사해 둡니다. 원본 사진은 읽기만 하고 바꾸지 않습니다.
  • 즐겨찾기한 칵테일과 최근 본 칵테일
  • 앱 설정(화면 테마, 첫 안내 완료 여부, 자동 업데이트 여부)
  • 온라인에서 받은 레시피 데이터 사본과 업데이트 확인 기록
  • 학습 기능이 들어 있는 판에서는 그 학습 진도와 모의시험 자가 평가 기록

3. 네트워크 사용

앱은 다음 목적에만 인터넷을 사용하며, 이때 사용자 데이터를 보내지 않습니다.

  • 레시피 데이터 업데이트: 정적 파일(manifest.json, 릴리스 JSON)을 HTTPS로 읽어 옵니다. 요청에는 일반적인 HTTP 접속 정보(IP 주소, 요청 시각, 앱의 User-Agent) 외에 다른 정보가 포함되지 않으며, 이 정보는 호스팅 제공자(GitHub Pages)의 서버 로그에 남을 수 있습니다. 호스팅 제공자의 처리는 GitHub 개인정보처리방침을 따릅니다.
  • 외부 링크: 레시피 원본 영상(YouTube)이나 출처 페이지를 열 때 기기의 브라우저 또는 해당 앱으로 이동합니다. 이동한 뒤의 데이터 처리는 해당 서비스의 정책을 따릅니다.
  • 전국 바 가이드: 바 목록은 앱에 들어 있는 자료이며 검색어를 밖으로 보내지 않습니다. 지도가 연결된 버전에서 지도를 열면 네이버 지도 SDK가 지도 화면을 받아 오면서 이용 정보(지도 요청, 기기·앱 정보)가 네이버(네이버 클라우드)로 전달됩니다. 네이버 지도·커뮤니티 게시판을 여는 단추를 누르면 해당 앱 또는 브라우저로 이동합니다.
  • 내 주변 바: 사용자가 "현재 위치로 찾기"를 눌렀을 때만 기기의 현재 위치를 한 번 읽어, 앱에 들어 있는 바까지의 직선거리를 기기 안에서 계산합니다. 위치는 기기에 저장하지 않고 운영자·네이버·그 밖의 누구에게도 보내지 않으며, 화면을 닫으면 사라집니다. 앱을 켤 때 위치를 묻지 않고, 앱을 쓰지 않는 동안(백그라운드)에는 위치를 읽지 않습니다.

지도를 뺀 앱의 기능은 인터넷에 연결되지 않아도 쓸 수 있습니다.

4. 백업 파일

사용자가 직접 "내 데이터 백업"을 실행하면 내 바(구매 가격·수량 포함), 즐겨찾기, 설정, 직접 등록한 술·음료·재료, 직접 쓴 레시피, 학습 기록이 담긴 JSON 파일이 만들어집니다. 사진은 파일이 아니라 앱 안의 경로만 들어갑니다. 파일은 사용자가 고른 위치에만 저장되고, 앱이 어디로도 전송하지 않습니다. 파일의 보관과 공유는 사용자의 책임입니다.

5. 제3자 SDK

앱은 광고, 분석, 오류 보고, 소셜 로그인 등 제3자 데이터 수집 SDK를 포함하지 않습니다. 전국 바 가이드의 지도에는 네이버 지도 SDK(네이버 클라우드 플랫폼 Maps)를 씁니다. 지도를 열 때 지도 표시에 필요한 이용 정보가 네이버로 전달되며, 그 처리는 네이버의 정책을 따릅니다. 지도가 연결되지 않은 버전에서는 전달되지 않습니다. "내 주변 바"의 현재 위치는 기기의 위치 서비스(Android 위치 서비스, Google Play 서비스의 위치 기능)에서 받습니다. 앱은 받은 위치를 어디에도 보내지 않으며, 기기 위치 서비스 자체의 처리는 기기 제조사·Google 의 정책을 따릅니다. 그 밖에 앱에 들어 있는 오픈소스 라이브러리는 기기 안에서만 동작합니다.

6. 권한

앱이 요청하는 Android 권한은 인터넷 접근(INTERNET)과, 지도 SDK가 연결 상태를 확인하는 데 쓰는 네트워크 상태 확인(ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE), 그리고 "내 주변 바"에서만 쓰는 위치(ACCESS_COARSE_LOCATION, ACCESS_FINE_LOCATION)입니다. 위치 권한은 사용자가 "현재 위치로 찾기"를 누를 때 묻고, 대략적인 위치만 허용하거나 거부해도 나머지 기능은 그대로 쓸 수 있습니다. 백그라운드 위치, 연락처, 카메라, 마이크, 저장소 전체 접근 권한을 사용하지 않습니다. 백업 파일 저장과 불러오기, 직접 등록 항목의 사진 고르기는 Android의 파일·사진 선택 화면을 통해 사용자가 고른 파일에만 접근합니다. 사진 보관함 전체를 읽는 권한은 요청하지 않습니다.

7. 데이터 삭제

기기 안의 데이터는 앱에서 직접 지우거나(내 바 항목 삭제, 직접 등록 항목·레시피 삭제, 즐겨찾기 해제, 받은 레시피 데이터 지우기), 앱을 삭제하면 함께 삭제됩니다. 직접 등록 항목을 지우면 그 항목에 복사해 둔 사진도 함께 지웁니다. 사용자가 만든 백업 파일은 사용자가 직접 지웁니다. 운영자는 사용자의 데이터를 보관하지 않으므로 별도의 삭제 요청 절차가 필요하지 않습니다.

8. 아동의 개인정보

앱은 아동을 대상으로 하지 않으며, 연령과 관계없이 개인정보를 수집하지 않습니다.

9. 방침의 변경

방침이 바뀌면 앱 업데이트 또는 이 페이지를 통해 알립니다. 바뀐 방침은 공개된 시행일부터 적용됩니다.
