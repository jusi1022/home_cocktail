홈칵테일 개인정보처리방침

시행일: 2026-11-25 · 적용 앱: 홈칵테일 (Android·iPhone, com.jusi1022.homecocktail) · 웹사이트 홈칵테일(https://homecocktail.kr)

1. 개요

홈칵테일(이하 "앱")은 칵테일 레시피와 주류 정보, 내 술장 관리 기능을 제공하는 앱입니다. Android와 iPhone에서 쓸 수 있습니다. 앱은 회원 가입이나 로그인 기능이 없으며, 사용자를 식별하는 정보를 수집하지 않습니다. 운영자는 사용자의 데이터를 받는 서버를 운영하지 않습니다.

2. 기기 안에 저장하는 데이터

다음 데이터는 모두 사용자의 기기 안(앱 전용 저장 공간)에만 저장되며, 운영자나 제3자에게 전송되지 않습니다.

  • 내 바에 등록한 술과 재료(이름, 분류, 수량, 메모)와 사용자가 적은 구매 가격
  • 사용자가 직접 등록한 술·음료·재료(이름, 종류, 브랜드, 도수, 용량, 구매일, 메모), 직접 쓴 칵테일 레시피, 내 제조법
  • 직접 등록 항목에 붙인 사진: 사용자가 고른 사진 파일을 앱 전용 폴더에 복사해 둡니다. 원본 사진은 읽기만 하고 바꾸지 않습니다.
  • 즐겨찾기한 칵테일과 최근 본 칵테일, 저장한 바와 메모
  • 장보기 목록(살 재료, 연결한 상품, 예상 가격, 실제 구매 가격, 메모)
  • 앱 설정(화면 테마, 첫 안내 완료 여부, 자동 업데이트 여부)
  • 온라인에서 받은 레시피 데이터 사본과 업데이트 확인 기록
  • 학습 기능이 들어 있는 판에서는 그 학습 진도와 모의시험 자가 평가 기록

3. 인터넷에서 받아 오는 것

앱은 아래 파일을 받아 올 때만 인터넷을 씁니다. 받기만 하고, 내 바·장보기 목록·검색어 같은 사용자 데이터를 보내지 않습니다.

  • 레시피 데이터 업데이트: 새 레시피 목록(정적 파일)을 HTTPS로 받습니다.
  • 참고 시세(장보기, Android용 앱): 장보기 줄에 상품을 연결하면, 공개된 판매가를 운영자가 요약해 만든 파일(제품별 최저·최고·평균·중앙값·판매처 수·확인 시각)을 HTTPS로 받아 기기 안에서 보여 줍니다. 출처는 화면에 "데일리샷 기준"으로 표시합니다. 앱은 데일리샷 서버에 직접 접속하지 않으며, 주류를 판매하거나 주문을 받지 않습니다. 가격은 참고용입니다. iPhone용 앱에서는 참고 시세를 제공하지 않으며 이 파일을 받지 않습니다.
  • 앱 업데이트 확인: Android용 앱은 Google Play의 업데이트 정보와 정적 버전 정보 파일을 읽습니다. iPhone용 앱은 앱 안에서 업데이트를 확인하지 않습니다.
  • 접속 기록: 위 파일은 GitHub Pages(호스팅 제공자)에서 받습니다. 파일을 받을 때 일반적인 접속 정보(IP 주소, 요청 시각, 요청한 프로그램의 종류)가 호스팅 제공자의 서버 기록에 남습니다. GitHub은 방문자의 IP 주소를 보안 목적으로 기록·보관한다고 밝히고 있습니다. 이 기록은 호스팅 제공자가 자신의 정책에 따라 다루며, 운영자는 이 기록을 받아 보지 않고 볼 수 있는 수단도 없습니다.

인터넷에 연결되지 않아도 앱에 들어 있는 레시피와 내 바, 장보기 목록, 바 목록은 그대로 쓸 수 있습니다.

4. 위치

"내 주변 바"에서 사용자가 "현재 위치로 찾기"를 눌렀을 때만 기기의 현재 위치를 한 번 읽습니다.

  • 읽은 위치로 앱에 들어 있는 바까지의 직선거리를 기기 안에서 계산해 가까운 순으로 보여 줍니다. 위치는 기기에 저장하지 않고 운영자·지도 서비스·그 밖의 누구에게도 보내지 않으며, 화면을 닫으면 사라집니다.
  • 앱을 켤 때 위치를 묻지 않고, 앱을 쓰지 않는 동안(백그라운드)에는 위치를 읽지 않습니다. 위치를 허용하지 않아도 지역을 골라 바를 찾을 수 있습니다.
  • Android는 기기의 위치 서비스(Google Play 서비스의 위치 기능 포함)에서, iPhone은 iOS 위치 서비스에서 위치를 받습니다. 위치 서비스 자체의 처리는 기기 제조사·Google·Apple의 정책을 따릅니다.

5. 제3자 SDK

앱은 광고, 분석, 오류 보고, 소셜 로그인 등 제3자 데이터 수집 SDK를 포함하지 않습니다.

지금 배포하는 버전(Android·iPhone 모두)에는 앱 안 지도가 연결되어 있지 않습니다. 앱 파일에 네이버 지도 SDK(네이버 클라우드 플랫폼 Maps)가 들어 있지만 실행되지 않으며, 앱은 네이버 서버에 접속하지 않습니다. 전국 바 가이드의 지도는 앱에 들어 있는 그림이고, 바의 위치를 지도에서 보려면 네이버 지도 앱이나 브라우저로 이동합니다(10절).

나중에 앱 안 지도를 연결하는 버전을 내면, 지도를 열 때 지도 표시에 필요한 이용 정보(지도 요청, 기기·앱 정보)가 네이버로 전달됩니다. 그 버전을 내기 전에 이 방침을 고쳐 알립니다.

그 밖에 앱에 들어 있는 오픈소스 라이브러리는 기기 안에서만 동작합니다.

6. 권한과 사진·파일 선택

  • Android: 인터넷 접근(INTERNET), 네트워크 상태 확인(ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE), "내 주변 바"에서만 쓰는 위치(ACCESS_COARSE_LOCATION, ACCESS_FINE_LOCATION).
  • iPhone: 위치(앱을 사용하는 동안 — "내 주변 바"에서만).
  • 위치 권한은 "현재 위치로 찾기"를 누를 때 묻습니다. 대략적인 위치만 허용하거나 거부해도 나머지 기능은 그대로 쓸 수 있습니다.
  • 사진: 직접 등록 항목에 사진을 붙일 때 기기의 사진 선택 화면이 열립니다. 앱은 사용자가 고른 사진 한 장만 받습니다. 사진 보관함 전체를 읽는 권한은 요청하지 않습니다. iPhone에서는 "사진 보관함에서 선택"(시스템 사진 선택 화면)과 "파일에서 선택"(파일 앱) 가운데 고를 수 있습니다.
  • 파일: 백업 파일 저장과 불러오기는 기기의 파일 선택 화면에서 사용자가 고른 파일에만 접근합니다.
  • 백그라운드 위치, 연락처, 카메라, 마이크, 저장소 전체 접근 권한을 사용하지 않습니다.

7. 백업 파일

사용자가 직접 "내 데이터 백업"을 실행하면 내 바(구매 가격·수량 포함), 즐겨찾기, 설정, 장보기 목록, 직접 등록한 술·음료·재료, 직접 쓴 레시피, 내 제조법, 학습 기록이 담긴 JSON 파일이 만들어집니다.

  • 파일은 사용자가 고른 위치에 저장됩니다. 앱이 어디로도 보내지 않습니다.
  • 사용자가 iCloud Drive, Google Drive 같은 클라우드 저장 위치를 고르면 그 파일은 그 서비스에 올라갑니다. 올라간 파일의 처리는 그 서비스의 정책을 따릅니다. 메신저나 메일로 파일을 보내는 경우도 같습니다.
  • 사진은 파일이 아니라 앱 안의 경로만 들어갑니다. 그래서 다른 기기로 옮기면 사진은 따라가지 않습니다.
  • Android와 iPhone이 같은 형식을 써서 서로 불러올 수 있습니다.
  • 파일의 보관과 공유는 사용자의 책임입니다.

8. 데이터 삭제

  • 기기 안의 데이터: 앱에서 직접 지우거나(내 바 항목 삭제, 직접 등록 항목·레시피 삭제, 즐겨찾기 해제, 받은 레시피 데이터 지우기), 앱을 삭제하면 함께 삭제됩니다. 직접 등록 항목을 지우면 그 항목에 복사해 둔 사진도 함께 지웁니다.
  • 백업 파일: 앱을 삭제해도 사용자가 따로 저장한 백업 파일은 지워지지 않습니다. 기기의 파일 앱이나 클라우드 저장소에 둔 파일은 사용자가 직접 지워야 합니다.
  • 운영자는 사용자의 데이터를 보관하지 않으므로 별도의 삭제 요청 절차가 필요하지 않습니다.

9. 아동

앱은 술에 관한 정보를 다루며 성인을 대상으로 합니다. 연령과 관계없이 개인정보를 수집하지 않습니다.

10. 외부 링크

레시피 원본 영상(YouTube), 출처 페이지, 네이버 지도, 커뮤니티 게시판, 참고 시세의 "원본 상품 보기"(데일리샷 상품 페이지)를 누르면 기기의 브라우저나 해당 앱으로 이동합니다. 이동한 뒤의 데이터 처리는 그 서비스의 정책을 따릅니다.

11. 방침의 변경

방침이 바뀌면 앱 업데이트 또는 공개 페이지를 통해 알립니다. 바뀐 방침은 공개된 시행일부터 적용됩니다.

웹사이트(homecocktail.kr)

홈칵테일 웹사이트는 회원 가입·로그인 기능이 없고, 쿠키·방문 분석·광고 도구를 쓰지 않으며, 방문자를 식별하는 정보를 수집하지 않습니다. 사이트는 GitHub Pages 에서 제공되므로 페이지를 열 때의 일반적인 HTTP 접속 정보(IP 주소, 요청 시각, 브라우저 정보)가 호스팅 제공자의 서버 로그에 남을 수 있습니다. 그 처리는 GitHub 개인정보처리방침을 따릅니다.

  • 전국 바 가이드의 지도: 방문자가 "지도", "지도에서 위치 보기", "내 주변 바 찾기"를 누르거나 전국 지도에서 지역을 고를 때만 OpenStreetMap 재단(OSMF)의 지도 타일 서버(tile.openstreetmap.org)에서 지도 그림을 받아 옵니다. 이때 브라우저가 지도 그림 요청과 함께 IP 주소, 브라우저 정보(User-Agent), 이 사이트의 주소(Referer)를 그 서버로 보냅니다. 그 처리는 OSMF 개인정보처리방침을 따릅니다. 지도를 열지 않으면 이 요청은 일어나지 않습니다. 지도 라이브러리(Leaflet)는 사이트 안에 들어 있어 따로 외부에서 받지 않습니다.
  • 바 검색과 거르개: 이름·지역 검색어와 거르개는 브라우저 안에서만 처리하며 운영자나 다른 곳으로 보내지 않습니다.
  • 내 주변 바 찾기: 방문자가 "📍 내 주변 바 찾기"를 눌렀을 때만 브라우저가 위치 권한을 묻고, 허용하면 현재 위치를 한 번 읽습니다. 위치는 그 페이지의 메모리에서 바까지의 직선거리를 계산하는 데만 쓰며, 운영자 서버·분석 도구 등 어디로도 보내지 않고 저장하지 않습니다(쿠키·브라우저 저장소·주소창에도 남기지 않습니다). 위치를 계속 추적하지 않고, 페이지를 닫거나 "현재 위치 검색 끄기"를 누르면 사라집니다. 다만 결과를 지도로 보여 줄 때 현재 위치 주변의 지도 그림을 OSMF 지도 타일 서버에서 받아 오므로, 그 요청으로 대략적인 지역이 그 서버에 전달될 수 있습니다. 현재 위치를 허용하지 않아도 지역·동네·역 이름으로 찾을 수 있습니다.
  • 외부 링크: "네이버 지도에서 보기"·공식 계정·출처 링크를 누르면 해당 서비스로 이동하며, 이동한 뒤의 데이터 처리는 해당 서비스의 정책을 따릅니다.
